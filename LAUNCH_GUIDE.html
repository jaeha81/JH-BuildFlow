🚀 전체 서비스 한 번에 실행

프로젝트 루트에서 아래 명령어 1개로 API + 협력사 포털 + 관리자 모바일 동시 시작

cd "D:\ai프로젝트\JH BuildFlow"
npm run dev

※ Python 3.11+ 및 Node.js 18+ 필요. 처음 실행 시 npm install 먼저 실행

📡 포트 및 역할 요약
서비스 포트 접속 주소 대상
API 서버 (FastAPI) 8000 http://localhost:8000 내부 전용
협력사 포털 (vendor-web) 3000 http://[IP]:3000 외부 협력사
관리자 모바일 (admin-web) 3001 http://[IP]:3001 관리자 (모바일)
관리자 데스크탑 (Electron) exe 실행 설치 후 바로 실행 관리자 (PC)
⚙️ API 서버 개별 실행 (선택)
cd "D:\ai프로젝트\JH BuildFlow\apps\api"
pip install -r requirements.txt
uvicorn main:app --reload --port 8000

API 문서: http://localhost:8000/docs

🔧 관리자 데스크탑 개발 모드 실행
cd "D:\ai프로젝트\JH BuildFlow\apps\admin-desktop"
npm run electron:dev

Vite 렌더러(5173) + TypeScript 빌드 + Electron 동시 실행

📦 exe 다시 빌드
# 포터블 (설치 불필요)
cd "D:\ai프로젝트\JH BuildFlow\apps\admin-desktop"
npm run build
npx electron-builder --win portable --x64

npx electron-builder --win nsis --x64
